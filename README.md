# Bahu Beti Collection — Manasa

A modern and responsive website developed for **Bahu Beti Collection, Mansa**, a local **girls' clothing and fashion store** in Madhya Pradesh.

## About the Project

**Bahu Beti Collection** is a local girls' clothing shop based in **Mansa, Madhya Pradesh**.

This website was created to help the business establish a professional online presence and make its clothing collections easier for customers to discover online.

## Features

* Modern and clean fashion-focused design
* Fully responsive layout
* Mobile-friendly interface
* Clothing collection showcase
* Business information
* Contact details
* Location information
* Easy navigation
* User-friendly interface

## Tech Stack

* **HTML5** — Website structure
* **CSS3** — Styling and responsive design
* **JavaScript** — Interactive functionality
